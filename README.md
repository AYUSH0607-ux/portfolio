## 🌐 How to Publish Online for Free

You can put this website on the internet so recruiters, professors, and friends can visit it anytime:

### Method 1: GitHub Pages (Recommended)
1. Go to your GitHub account: [https://github.com/AYUSH0607-ux](https://github.com/AYUSH0607-ux)
2. Create a new repository named `AYUSH0607-ux.github.io` (or `portfolio`).
3. Push/upload your files: `index.html`, `style.css`, and `script.js`.
4. Go to **Settings > Pages** and select **Branch: main / root**.
5. Your portfolio will be live at: `https://ayush0607-ux.github.io/`!

### Method 2: Vercel (Instant 30 Seconds)
1. Sign in with GitHub at [vercel.com](https://vercel.com).
2. Click **Add New Project** and import your repository.
3. Click **Deploy**—done!
